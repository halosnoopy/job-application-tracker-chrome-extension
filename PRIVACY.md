# Privacy Policy

Job Application Tracker is a local-first Chrome extension for saving and reviewing job application records.

## Data Stored by the Extension

The extension may store the following information when the user saves a job application:

- Company name
- Job title
- Platform
- Application status
- Notes entered by the user
- Job posting URL
- Submission date

This data is stored locally in Chrome extension storage unless the user chooses to export it or back it up.

## Website Content

When the user clicks Local Extract or AI Extract, the extension may read content from the active job posting page to identify job details such as company name, job title, platform, and URL.

## Optional AI Extraction

If the user clicks AI Extract and has configured a Gemini API key, selected job page information may be sent to the Gemini API to extract job details. AI extraction is optional.

## Optional Google Drive Backup

If the user uses Google Drive backup, saved application records are uploaded to the user’s own Google Drive as a backup JSON file. The extension uses Google Drive only for backup, restore, and removing the backup file.

## Data Sharing

The extension does not sell user data. The extension does not use user data for advertising, creditworthiness, lending, or unrelated purposes.

Data is only transferred when the user explicitly uses optional features such as AI extraction or Google Drive backup.

## Data Removal

Users can delete records from the dashboard, reset all local records, export records to CSV, or remove the Google Drive backup file.

Uninstalling the extension may remove local extension storage from Chrome.

## Contact

For questions, contact the developer through the extension’s GitHub repository.
